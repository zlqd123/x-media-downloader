# X 媒体原图抓取器（Edge / Chromium 扩展）

抓取 x.com / twitter.com 页面（尤其**用户媒体页** `https://x.com/<用户名>/media?filter=photo`）的全部图片，自动把缩略图链接还原为**上传原图**并批量下载。在你自己的浏览器里运行、复用当前登录态，不需要也不读取任何 Cookie。

## 功能

- **滚动 + 扫描合一**：打开弹窗即自动扫描当前页；「滚动加载全部」慢速逐屏滚动到底（每屏 3 秒）+ 底部抖动重触发懒加载，连续 8 轮无新增才停止，全程按图片 ID 收集去重；并按页面标题「N 照片和视频」总数自动核对
- **下载全部原图**：缩略图 → 原图还原 + 并发批量下载（HEAD 探测取最大原图）
- **持久化 ID 缓存去重**：下载记录与最近清单持久化（chrome.storage.local），跨会话按图片 ID 去重；重开弹窗自动恢复清单，已下载自动跳过（清空需二次确认）
- **下载记录导入 / 导出**（JSON）：可导出备份，换机或重装后导入合并
- **导出链接清单**（CSV，带 BOM，可直接用 Excel 打开）
- **保存路径可配**：总文件夹可留空（直接进下载目录），作者子文件夹可开关

## 安装

1. 地址栏打开 `edge://extensions`
2. 打开左下角「**开发人员模式**」
3. 点「**加载解压缩的扩展**」，选择本目录 `x-media-downloader`
4. 工具栏出现图标即安装完成（可固定到工具栏）

Chrome 同理：打开 `chrome://extensions` 按上述步骤加载。

## 使用

1. 登录你的 x.com 账号，打开目标媒体页，例如 `https://x.com/<用户名>/media?filter=photo`
2. 点工具栏扩展图标（打开即自动扫描当前页）
3. **① 滚动加载全部**（滚动 + 扫描合一，图片多时需要几分钟）→ **② 下载全部原图**
4. 下载过的图片按 ID 记录，下次自动跳过

## 保存路径

`下载目录/[总文件夹]/[作者子文件夹]/文件名.扩展名`，两层文件夹均可关：

| 总文件夹 | 作者子文件夹 | 落盘路径 |
| --- | --- | --- |
| `x_media` | 开（默认） | `下载目录/x_media/<用户名>/xxx.jpg` |
| `x_media` | 关 | `下载目录/x_media/xxx.jpg` |
| 留空 | 开 | `下载目录/<用户名>/xxx.jpg` |
| 留空 | 关 | `下载目录/xxx.jpg`（完全不套） |

## 原图还原规则（2026-11 实测验证）

用真实媒体 ID 逐条 GET 实测（页面缩略图为 `?name=small`）：

| 候选形态 | 结果 |
| --- | --- |
| `ID.{格式}?name=orig` | ✅ 上传原图 |
| `ID?format={格式}&name=orig` | ✅ 同上 |
| `ID.{格式}:orig`（旧式） | ✅ 同上 |
| `ID?name=orig`（无 format） | ❌ 404，已从候选剔除 |
| `name=large` | ⚠️ 2048px 中档图，仅作兜底 |

下载前对候选做 HEAD 探测，取 `content-type` 为图片且字节数最大者——即使 CDN 行为变化也会自动收敛到最大的图。

## 选项

| 选项 | 说明 | 默认 |
| --- | --- | --- |
| 总文件夹 | 下载目录内的子目录；**留空 = 不套** | `x_media` |
| 作者子文件夹 | 按 `<用户名>` 分子文件夹，可关 | 开 |
| 文件命名模式 | `{user}` 用户名 / `{id}` 媒体 ID / `{index}` 序号(0001) | `{user}_{id}` |
| 跳过已下载 | 按媒体 ID 去重 | 开 |
| 并发数 | 1–6 | 3 |

## 下载记录（去重缓存）

- 记录按**图片 ID** 存于浏览器本地（`chrome.storage.local`），跨会话、跨扫描生效
- 「导出下载记录」生成 `xmd_download_history.json`；「导入下载记录」按 ID 合并（已有记录优先），换机/重装后之前的图自动跳过
- 「清空已下载记录」为二次确认（3 秒内再点一次才执行）

## 注意事项

- 扩展只在本机运行，不上传任何数据；仅申请 downloads / storage / scripting 等必要权限
- 需要登录 x.com 才能浏览用户媒体页；扩展复用浏览器现有登录态，不读取 Cookie
- 浏览器限制下载路径必须在下载目录之内；总文件夹 / 作者子文件夹均为下载目录内的可选子目录
- 若遇到「扫描不到图片」：确认页面已登录、图片已渲染，重新打开弹窗会自动扫描
- 请仅下载你有权保存的内容，遵守 x.com 服务条款与版权规定
